# taugine
tau is 2pi. The name taugine is a play on the first game engine I wrote for my still unreleased (better get on that) game "Pi Must Die", which I've spent nearly 4 years working on at this point.

The engine is written with OpenGL and SDL3.

Right now the engine is tied directly to a demo for it, but I'll separate them at some point, and move the demos to an examples directory.

You could probably tell that I'm pretty new with Zig. I'm possible underutilizing features like tests and comptime, but I'll figure those out later.
